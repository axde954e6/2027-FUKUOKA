🗂 未來備用行程｜阿蘇

原 2027 九州行程規劃，因本次取消阿蘇住宿而移出正式行程。保留作為未來熊本／阿蘇自駕旅行參考。

建議順序：草千里 → 阿蘇火山博物館 → 中岳火口 → 上色見熊野座神社 → 阿蘇神社

草千里
阿蘇代表性的草原景觀，可以與阿蘇火山博物館、午餐安排在同一區域。
阿蘇火山博物館
位於草千里附近，若未來安排阿蘇自駕，可以與草千里一起遊覽。
中岳火口
草千里之後可以繼續前往；是否開放以當日火山活動、火山氣體濃度與氣象管制為準。
上色見熊野座神社
位於高森方向，特色為杉木參道、石燈籠與森林景觀。若未來規劃阿蘇＋高森一帶，可以一起安排。
阿蘇神社
適合作為阿蘇北側行程最後一站，可以搭配門前町散步。

備註：以上為原阿蘇自駕規劃留下的景點清單。未來若安排熊本／阿蘇旅行，可再依住宿位置、火山管制與當時營業時間重新調整順序。
